# Checklist de Accesos JAL - distribucion

Instalador y actualizaciones de la aplicacion de escritorio.

**Instalar:** https://jjcambresjal.github.io/CHECKLIST_JAL_DEPLOY/

Este repositorio contiene unicamente la aplicacion compilada. No contiene datos de
personas, ni de accesos, ni base de datos alguna: la aplicacion los consulta al servidor
de la firma cuando el usuario entra con su cuenta.

El codigo fuente esta en el repositorio privado `CHECKLIST_JAL`.
